# EPM Data

[EPM Data](https://www.epm.se/) offers private, public, and hybrid cloud infrastructure.

EPM Data is headquartered in Sweden.

The minimum quotas needed to be able to deploy {{ product_name }} in your account is listed on [Sizing of {{ product_name }}](../../for-administrators/plan-your-environment/sizing.md).

If you are an existing EPM customer, talk to your EPM representative to setup {{ product_name }} in your account.

If you would like to become an EPM customer, sign up for one of their clouds and talk to EPM to get {{ product_name }}.
