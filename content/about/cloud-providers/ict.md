# ICT Cloud

ICT Cloud offers private cloud.

The minimum quotas needed to be able to deploy {{ product_name }} in your account is listed on [Sizing of {{ product_name }}](../../for-administrators/plan-your-environment/sizing.md).

ICT Cloud is headquartered in Germany.

If you are an existing ICT Cloud customer, email [`sales@stakater.com`](mailto:sales@stakater.com) to get a quote for {{ product_name }} in your account.

If you would like to become an ICT Cloud customer, sign up for one of their clouds and email [`sales@stakater.com`](mailto:sales@stakater.com) to get a quote for {{ product_name }}.
