# UpCloud

An account is needed to run {{ product_name }} on [UpCloud](https://upcloud.com/).

The minimum quotas needed to be able to deploy {{ product_name }} in your account is listed on [Sizing of {{ product_name }}](../../for-administrators/plan-your-environment/sizing.md).

UpCloud is headquartered in Finland.

If you are an existing UpCloud customer, email [`sales@stakater.com`](mailto:sales@stakater.com) to get a quote for {{ product_name }} in your account.

If you would like to become a UpCloud customer, [sign up](https://signup.upcloud.com/) for their public cloud and email [`sales@stakater.com`](mailto:sales@stakater.com) to get a quote for {{ product_name }}.
