# `OVHCloud`

An OpenStack account is needed to run {{ product_name }} on [`OVHCloud`](https://www.ovhcloud.com/en/).

The minimum quotas needed to be able to deploy {{ product_name }} in your account is listed on [Sizing of {{ product_name }}](../../for-administrators/plan-your-environment/sizing.md).

`OVHCloud` is headquartered in France.

If you are an existing `OVHCloud` customer, email [`sales@stakater.com`](mailto:sales@stakater.com) to get a quote for {{ product_name }} in your account.

If you would like to become an `OVHCloud` customer, [sign up](https://www.ovhcloud.com/en/public-cloud/) for their public cloud and email [`sales@stakater.com`](mailto:sales@stakater.com) to get a quote for {{ product_name }}.
