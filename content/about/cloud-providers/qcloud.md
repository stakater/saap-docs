# `Qaumi Cloud` (`QCloud`)

[`QCloud`](https://qcloud.pk/) offers private cloud infrastructure.

`QCloud` is headquartered in Pakistan.

The minimum quotas needed to be able to deploy {{ product_name }} in your account is listed on [Sizing of {{ product_name }}](../../for-administrators/plan-your-environment/sizing.md).

If you are an existing `QCloud` customer, email [`sales@stakater.com`](mailto:sales@stakater.com) to get a quote for {{ product_name }} in your account.

If you would like to become a `QCloud` customer, [contact `QCloud`](https://qcloud.pk/contact-us/) to get a quote.
