# RHACS

Red Hat Advanced Cluster Security provides runtime security for your cluster. It scans container images for vulnerabilities, detects anomalous behaviour at runtime, enforces image policies, and produces compliance reports.

RHACS is an optional add-on. Contact [Stakater Support](https://support.stakater.com) to enable it for your cluster.
