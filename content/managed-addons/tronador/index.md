# Tronador

Tronador automatically creates and tears down preview environments for pull requests. When you open a PR, Tronador provisions a dedicated namespace and deploys your application into it. When the PR is merged or closed, the environment is removed.

Reviewers get a running version of the change to test against — no manual deployment steps required.

For full configuration and usage, see the [Tronador documentation](https://docs.stakater.com/tronador/).
